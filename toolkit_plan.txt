
PERSONAL MINI-TOOLKIT PLAN

PROJECT TITLE:
Personal Mini-Toolkit

TOOL 1: SIMPLE CALCULATOR
This tool allows users to add, subtract, multiply and divide two numbers.
Concepts: Variables, input, calculations and conditionals.

TOOL 2: TO-DO LIST
This tool allows users to add, view and remove tasks.
Concepts: Lists, loops and conditionals.

TOOL 3: EVEN OR ODD CHECKER
This tool checks whether a number is even or odd.
Concepts: Variables, input and if/else statements.

TOOL 4: MULTIPLICATION TABLE
This tool generates a multiplication table from 1 to 10.
Concepts: Loops and f-strings.
